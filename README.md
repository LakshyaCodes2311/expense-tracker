# 💰 Python Expense Tracker

A simple **Expense Tracker** built using Python that allows users to record and manage their daily expenses through the terminal.

## 📌 Features

* ➕ Add new expenses
* 📋 View recorded expenses
* 🏷️ Categorize expenses
* 💵 Calculate total expenses
* 🖥️ Simple command-line interface
* 🐍 Built completely using Python

##  Technologies Used

* **Python**
* Python lists and dictionaries
* Loops
* Conditional statements
* Functions
* User input
* Formatted output

##  How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python expense_tracker.py
```

5. Follow the instructions displayed in the terminal.
